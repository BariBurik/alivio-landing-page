# Alivio Landing Page

Landing page implemented from a Figma design using HTML and CSS.

The project focuses on reproducing the original desktop layout, typography, spacing, visual hierarchy, and page sections from the provided design.

## Live Demo

**GitHub Pages:**
https://bariburik.github.io/alivio-landing-page/

## Preview

![Alivio Landing Page](./1920_Landing%20Page_Final.png)

## Features

* Figma-to-HTML implementation
* Multi-section landing page
* Semantic HTML structure
* Navigation between page sections
* Custom fonts
* CSS variables for reusable colors
* Flexbox-based layouts
* Reusable button and text styles
* Local image assets
* GitHub Pages deployment

## Tech Stack

* HTML5
* CSS3
* Figma
* GitHub Pages

## Page Sections

The landing page includes:

* Navigation header
* Hero section
* "How it works" section
* Three-step feature section
* Customer success story
* Product presentation
* Footer navigation

## Running Locally

No package installation or build process is required.

Clone the repository:

```bash
git clone https://github.com/BariBurik/alivio-landing-page.git
cd alivio-landing-page
```

Open `index.html` directly in your browser.

Alternatively, run a simple local HTTP server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Current Layout

The current version is designed primarily for a 1920px desktop viewport.

Responsive and mobile adaptation are not implemented yet.
